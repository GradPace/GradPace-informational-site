Glossary

Key terms and definitions for the GradPace project

Alumni
Graduates of a university who use GradPace to complete industry surveys and share insight on current skills and hiring trends.
API (Application Programming Interface)
A set of rules that allow different software applications to communicate and exchange data with each other.
Authentication
The process of verifying a user's identity before allowing access to a system.
Backend
The server-side part of a website or application that handles logic, databases, and data processing.
Career Readiness
A measure of how prepared a student is to enter a specific career based on skills, experience, and qualifications.
Career Roadmap
A structured, visual plan that outlines a student's progress, goals, and required steps toward a specific career path.
Cloud Computing
The use of remote servers on the internet to store data and run applications instead of a local computer.
Data Leak
The accidental or unauthorized exposure of sensitive or private information.
Database
An organized collection of data that can be stored, accessed, and managed electronically.
Django
An open-source Python web framework used to build the GradPace application layer.
Django REST Framework (DRF)
A toolkit built on Django for creating RESTful web APIs that the frontend uses to exchange data with the backend.
Docker
A platform that packages applications and their dependencies into containers so they run consistently across development machines and servers.
Encryption
A security method that converts data into a coded form so that only authorized parties can read it.
Events API
An external interface used to retrieve information about networking events, career fairs, and similar opportunities.
FERPA (Family Educational Rights and Privacy Act)
A U.S. federal law that protects the privacy of student education records.
Frontend
The user-facing part of a website or application that users interact with in their browser.
Gap Detection (Early-Warning System)
A feature that identifies missing skills, experiences, or qualifications needed for a target career.
Google Maps API
Google's location service interface used to determine proximity between a user and nearby events or opportunities.
GPAI (GradPace AI)
GradPace's locally hosted AI model (Gemma 4 E2B, served via llama.cpp). It reads each event's title and description and returns the skills the event covers, which the system matches against students' skill gaps. Student data is not sent to third-party AI services.
IEEE (Institute of Electrical and Electronics Engineers)
A professional organization that publishes technical standards, including the IEEE 830-1998 standard for software requirements specifications.
Industry Readiness Benchmarking
The process of comparing a student's profile against expected skills and qualifications for specific careers.
Job Benchmark
The list of desired skills for entry-level roles in a given field, found based on how frequently they are mentioned in job postings.
Location-Based Event Recommendations
Suggestions for nearby internships, networking events, or career opportunities based on user location.
MFCD (Major Functional Component Diagram)
A diagram showing the major hardware and software components of a system and how they interact.
ORM (Object-Relational Mapping)
A programming technique that translates data between a relational database and object-oriented code; GradPace uses the Django ORM.
PostgreSQL
An open-source relational database management system used for the GradPace data layer.
Professional Data Input
User-provided information such as coursework, projects, internships, and certifications used to build a profile.
Proficiency Level
The level at which a student believes they are experienced in a certain skill, rated from Beginner to Expert. Higher proficiencies have a larger effect on their readiness score.
Prototype
A limited, working version of GradPace built to demonstrate and validate core functionality before the real world product is developed.
React
A JavaScript library for building component-based user interfaces, used for the GradPace frontend.
Readiness Score
A 0-100 score meant to visualize how close a student is to the skill benchmark based on a job they target. Higher scores mean the student is an optimal candidate for the role, while lower scores mean there is work to be done.
REST (Representational State Transfer)
An architectural style for web services in which clients and servers exchange resources over standard HTTP methods.
RWP (Real World Product)
The complete, production-ready version of GradPace as envisioned beyond the scope of the prototype.
Skill Gap
Skills that are frequently desired based on job postings for a certain role have a high relevance for that role. A student that has no experience, or little experience with this skill has a skill "gap", which refers to the skills that need to be acquired to become an optimal candidate.
SRS (Software Requirements Specification)
A document that describes the functional and non-functional requirements of a software system.
Survey Results Dashboard
A feature that displays aggregated insights from alumni data to inform students and administrators.
System Administrator
A role responsible for managing the platform, maintaining data quality, and overseeing system functionality.
Tailwind CSS
A utility-first CSS framework used to style the GradPace user interface.
Token (AI)
A small unit of text processed by an AI model, such as a word, part of a word, or punctuation.
Target Role
GradPace benchmark data is acquired over many job postings, where the skills are counted and given relevance scores based on the type of role the job is. A student picks a target role as they sign up for the platform based on what they want to do after graduation, and their profile is referenced against the benchmark for that target role, providing the readiness score.
TypeScript
A typed superset of JavaScript used to write the GradPace frontend.
User Interface (UI)
The visual elements of a software application that allow users to interact with it.
Vite
A frontend build tool and development server used to compile and serve the GradPace React application.
Web Server
A computer system or software that stores websites and delivers web pages to users when they request them through a browser.
